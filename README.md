## Setup Instructions

1. Clone the repository:
```bash
git clone https://github.com/Rudra070311/rudra.github.io.git
```

2. Add your profile picture as `profile.jpg` in the root directory

3. Open `index.html` in your browser to view the website

4. Customize the content in:
   - `index.html` - HTML structure and content
   - `styles.css` - Styling and layout
   - `script.js` - JavaScript interactions

## Customization

### Adding Your Profile Picture
Replace `profile.jpg` with your own image file in the root directory.

### Updating Contact Information
Edit the contact section in `index.html` with your:
- Phone number
- Email address
- Physical address
- Social media links

### Modifying Projects
Edit the projects grid section in `index.html` to add, remove, or update projects.

### Changing Colors
Modify the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #3498db;
    --accent-color: #e74c3c;
    /* ... other variables ... */
}
```
